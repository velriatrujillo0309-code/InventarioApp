
### Modulo de Gestion de Inventario
- Busqueda y consulta de productos ingresando el codigo identificador de cada articulo.
- Registro de nuevos productos especificando codigo, descripcion del articulo, precio unitario y la opcion de marcarlo como producto en oferta.
- Visualizacion del inventario completo en formato de lista, diferenciando visualmente los articulos estandar de aquellos que cuentan con precio de oferta.

### Modulo de Administracion de Usuarios
- Panel exclusivo para administradores con el conteo de usuarios registrados.
- Opciones para editar la informacion personal de los usuarios.
- Opcion para cambiar el rol asignado a un usuario (Administrador o Empleado).
- Opcion para remover o eliminar usuarios del sistema.

## Requisitos y Configurar Proyecto

### Requisitos Previos
- Entorno de desarrollo Android Studio.
- Kit de Desarrollo de Java (JDK) version 11 o superior.
- Cuenta y proyecto configurado en la consola de Firebase.

### Instrucciones de Instalacion
1. Obtener los archivos fuente del proyecto.
2. Descargar el archivo de configuracion google-services.json de la consola de Firebase e incluirlo dentro del directorio app del proyecto.
3. Abrir el proyecto en Android Studio y sincronizar las dependencias con Gradle.
4. Compilar y ejecutar la aplicacion en un emulador o dispositivo fisico A
